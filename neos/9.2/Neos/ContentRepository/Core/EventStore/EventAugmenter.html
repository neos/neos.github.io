EventAugmenter

final class EventAugmenter (View source)

internal  the publication of events is not API. Only used within command handing in of the content repository.
 

Normalizes domain events and adds meta-data

The {\Neos\ContentRepository\Core\EventStore\EventsToPublish} with the domain events {\Neos\ContentRepository\Core\EventStore\EventInterface} are mapped to the lower level normalized {\Neos\EventStore\Model\EventsForCommit}

Events in the event store, store important meta-data:

  • For publishing and rebase they can encode their command {\Neos\ContentRepository\Core\Feature\RebaseableCommand::enrichWithCommand()} (see command handers, cannot be augmented here)

  • For satisfying the original {\Neos\ContentRepository\Core\EventStore\Node::$timestamps} we set {[\Neos\ContentRepository\Core\EventStore\InitiatingEventMetadata::INITIATING_TIMESTAMP}

*](../../../../Neos/ContentRepository/Core/EventStore/InitiatingEventMetadata.html) For determining the authorship of events we set {[\Neos\ContentRepository\Core\EventStore\InitiatingEventMetadata::INITIATING_USER_ID}

*](../../../../Neos/ContentRepository/Core/EventStore/InitiatingEventMetadata.html) To correlate events, for event migrations or debugging, we define a correlation id based on the command name
